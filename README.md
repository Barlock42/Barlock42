## What I work on

- **Multi-model orchestration** — an orchestrator routes each physician's question to specialized
  models and tools, presented as a virtual medical panel of specialist avatars in one conversation.
- **RAG over medical and regulatory documents** — Mistral OCR, token-based chunking, Qwen3 embeddings,
  hybrid retrieval, reranking, source citations.
- **PII guardrail for patient data** — Microsoft Presidio with custom Russian-language recognizers
  (names, phones, national ID and health-insurance numbers with checksum validation, dates of birth,
  addresses) that block or redact personal data before it reaches the model.
- **Platform** — Kubernetes, Helm and GitHub Actions; Open WebUI workspaces behind a LiteLLM gateway;
  Zitadel SSO.
- **Mobile** — the Consilium Alterum app for Android and iOS, built with Flutter.
